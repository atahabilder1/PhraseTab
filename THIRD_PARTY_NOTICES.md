# Third-party notices

WordTab bundles the third-party material listed below. Everything else in this
repository — including all vocabulary definitions, example sentences and
translations — is original work created for WordTab.

---

## Vocabulary data

**None.** The dataset in `src/data/vocabulary.json` contains no third-party
content.

Every definition, example sentence, Bangla translation and Chinese translation
was written for WordTab and reviewed by hand. Nothing was copied from Oxford,
Cambridge, Merriam-Webster, Collins, WordNet, or any other dictionary or lexical
database. Each entry carries `"source": "wordtab-original"` to record this.

Word and phrase *selection* was informed by general knowledge of high-frequency
English vocabulary. A headword is a fact, not a creative work, and no list's
structure, ordering or annotations were reproduced.

If third-party lexical data is ever imported — for example the New General
Service List, or WordNet for synonym relations, both of which PLAN.md raises as
possibilities — its licence must be verified first and its attribution added to
this file before the data is committed.

### IBM Plex Sans, IBM Plex Mono

- Copyright 2017 IBM Corp. (https://github.com/IBM/plex)
- Licence: SIL Open Font License, Version 1.1
- Used for: body text, controls, and metadata labels

Both fonts are used unmodified and are not sold. The SIL Open Font License
permits bundling and redistribution with software under these conditions; the
full licence text accompanies each upstream project at the URLs above.

Bangla and Chinese translations are deliberately **not** bundled with a webfont.
They render in whatever face the reader's system provides for those scripts,
because shipping Noto Sans Bengali and a Simplified Chinese face would add
several megabytes to a page whose entire purpose is opening instantly.
